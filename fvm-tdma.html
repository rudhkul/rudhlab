FVM and TDMA, step by step

Discretise a one-dimensional wall with finite volumes, assemble the tridiagonal system, and solve it with the Thomas algorithm one row at a time. Then write the solver yourself and check it against the numbers on this page. Part of the getting started guide.

Step 2 of 9

Integrate the governing equation

The finite volume method integrates the conservation law over each control volume, rather than replacing derivatives at isolated grid points.

d/dx ( k dT/dx ) + q‴ = 0

Integrate from the west face w to the east face e of cell P and multiply by the cross-sectional area A:

kA (dT/dx)_e − kA (dT/dx)_w + q‴ A Δx = 0

For an interior cell, approximate each face gradient from the two neighbouring cell centres:

(kA/Δx)(T_E − T_P) − (kA/Δx)(T_P − T_W) + q‴ A Δx = 0

Collect the terms into the standard form:

aP·T_P = aW·T_W + aE·T_E + b aW = aE = kA/Δx aP = aW + aE b = q‴ A Δx

Boundary cells: the distance from a fixed-temperature wall to the first cell centre is Δx/2, so that face conductance is 2kA/Δx, not kA/Δx.

Step 3 of 9

Build every equation

Write every row with one sign convention: −aW·T(i−1) + aP·T(i) − aE·T(i+1) = b(i). Known wall temperatures move into the source term b.

CellaWaPaEb

The discretised equations

The first row has no west unknown and the last row has no east unknown. That is how the fixed wall temperatures enter a cell-centred system.

Step 4 of 9

Recognise the tridiagonal matrix

Each cell talks only to its immediate neighbours, so the coefficient matrix has at most three non-zero diagonals.

Sub-diagonal: −aWMain diagonal: aPSuper-diagonal: −aE

Why this matters: Gaussian elimination on a full N × N matrix costs about N³ operations. TDMA skips the zeros and needs only about 8N operations and storage for three diagonals.

Step 5 of 9

TDMA: forward elimination

Rewrite each row as T(i) = c(i)·T(i+1) + d(i). Sweep left to right, removing the dependence on the previous temperature.

Row 1: D1 = aP1 c1 = aE1 / D1 d1 = b1 / D1 Row i≥2: Di = aPi − aWi·c(i−1) ci = aEi / Di di = (bi + aWi·d(i−1)) / Di At the last row aE = 0, so cN = 0 and TN = dN.
CellDicidi

Di is the modified pivot. Never divide by a zero or tiny pivot. Here the boundary rows are strictly diagonally dominant (aP > aW + aE), which keeps every Di positive.

Step 6 of 9

TDMA: back substitution

The last row already gives the last temperature. Walk back through the rows, recovering one temperature at each step.

TN = dN Ti = di + ci·T(i+1), i = N−1, …, 1
Cellx (m)T (°C)

Keep these apart: forward elimination computes modified coefficients; back substitution computes the temperatures. TDMA is a direct solver: it gives the exact algebraic answer in one pass, with no iterations to converge.

2 · Measure the order of accuracy
Loop over N = 4, 8, 16, 32, 64 and print the largest error against the exact solution. Compute the observed order as log2(E_N / E_2N) and compare it with the mesh-refinement table in step 7.


3 · Race a dense solver
Build the full N × N matrix with NumPy and solve it with numpy.linalg.solve. Check that both answers agree to round-off, then time both for N = 500, 1000 and 2000. How does each time grow when N doubles?


4 · Variable conductivity
Let k vary across the wall, for example k(x) = 1 + x. Each face now has its own conductance. Use the harmonic mean of the two neighbouring cell conductivities at interior faces, so the matrix stays tridiagonal and TDMA still applies unchanged.


5 · Towards 2D
In two dimensions each cell also couples to its north and south neighbours, so the matrix is no longer tridiagonal. The line-by-line method treats one row of cells at a time as a 1D TDMA problem, moving the other neighbours to the right-hand side, and sweeps until the solution stops changing. Read Patankar (1980), chapter 4, or Versteeg and Malalasekera, chapter 7, before trying it.
